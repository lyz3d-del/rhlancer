# GPT 小龙娘

以网友创作的 GPT 白发龙娘为参考制作的 Q 版动画桌宠素材。

![动画预览](preview.gif)

## 文件

- `spritesheet.png`：透明 PNG 动画图集，1536 × 2288，8 列 × 11 行，每格 192 × 208。
- `pet.json`：便于兼容桌宠程序接入的角色及图集元数据。
- `character.png`：用户确认的 Q 版外观概念图。
- `preview.gif` / `preview.mp4`：九组状态动画预览。
- `contact-sheet.png`：全部动作帧总览。
- `thinking.gif`：托腮、眨眼、抬眼的思考循环预览。

## 动画

前九行依次为待机、向右移动、向左移动、挥手、跳跃、失败反应、等待、思考工作、检查结果，帧数为 6、8、8、4、5、8、6、6、6。

最后两行包含 16 个顺时针视线方向，从正上方开始，每 22.5° 一个方向。空余格保持透明。文件通过了图集尺寸、透明度、帧完整性及方向检查。

接入其他桌宠程序时，请按上述布局适配帧顺序及状态映射；仓库不包含桌宠运行程序。

### 思考动画

![思考循环](thinking.gif)

思考工作对应 `running` 状态（零起始第 7 行），包含 6 帧，应循环播放；这不是脚步奔跑状态。应用何时进入该状态由宿主控制。ChatGPT Pets v2 固定各状态帧数，不能通过增加图集列数或额外帧提高宿主帧率。
